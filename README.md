# MindMate AI – Emotional Wellness Companion 🤖💙

MindMate AI is an AI-powered emotional wellness companion that provides empathetic conversations and personalized support using Generative AI. The system is designed to understand user emotions, maintain conversation context, and provide meaningful responses.

## Features

- 💬 AI-based emotional support chatbot
- 🧠 Conversation memory and context awareness
- 😊 Mood tracking system
- 🔄 Personalized responses based on user interactions
- 📚 Retrieval-Augmented Generation (RAG) support
- 🎙️ Voice input capability
- 👤 User-specific chat history

## Technologies Used

- Python
- Streamlit
- Ollama
- LangChain
- FAISS
- Sentence Transformers
- SQLite

## Project Description

MindMate AI acts as a virtual emotional companion that helps users express their thoughts and feelings through natural conversations. It uses Generative AI techniques to provide supportive responses while remembering previous interactions for better continuity.

## Installation

1. Clone the repository
2. Install the required dependencies
3. Run the application using Streamlit
